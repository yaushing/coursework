# Instructions for use:
1. Download [python 3.9.12](https://www.python.org/downloads/release/python-3912/)
2. Download latest release
3. Enter terminal in the root directory of this project and run:
```pip3 install -r modules.txt```
4. Run the following command to start a python shell:
```
python3
```
5. Run the following commands in the shell:
```
>>> import nltk
>>> nltk.download()
```
6. Download all.
7. Run game.py
